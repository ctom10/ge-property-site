# GE Property Development website

One-page site for GE Property Development (general contracting, Saranac Lake, NY).

- `index.html` - the whole page (styles and script inline)
- `logo.png` - company logo
- `work/` - project photos (`NN.jpg`) and their thumbnails (`tNN.jpg`) for the slideshow

Hosted with GitHub Pages from the `main` branch, root folder.
